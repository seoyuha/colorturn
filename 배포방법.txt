COLOR TURN ENGLISH — 온라인 대전 서버

[들어 있는 것]
- server.js   : 게임 서버 (2인·3인 자동 배정, 반별 랭킹, 교사 현황)
- engine.js   : 게임 규칙 (화면과 서버가 같이 씀)
- public/index.html : 게임 화면 (서버가 이 화면도 같이 보여 줌)
- package.json

[Render에 올리기]
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올려요. (node_modules, data.json은 올리지 않아도 돼요)
2. render.com → New → Web Service → 그 저장소 선택
3. Build Command: npm install
   Start Command: npm start
4. (선택) Environment에 TEACHER_PIN 을 넣으면 교사 비밀번호가 그 값으로 바뀌어요. 안 넣으면 지금 비밀번호 그대로예요.
5. 만들어진 주소(예: https://color-turn.onrender.com)를 학생들에게 나눠 주면 끝이에요.
   이 주소 하나로 AI 대전·2인·3인 대전·교사 관리가 모두 돼요.

[알아 둘 것]
- Render 무료 요금제는 15분 동안 아무도 안 쓰면 잠들어요. 수업 시작 전에 선생님이 주소를 한 번 열어 두면 깨어나요(30초~1분).
- 무료 요금제는 서버가 다시 켜질 때 랭킹 파일(data.json)이 지워질 수 있어요. 랭킹을 계속 남기려면 Render의 유료 Disk를 붙이고 DATA_FILE 환경변수로 그 경로를 지정해요.
- GitHub Pages에 올린 index.html에서도 온라인 대전을 쓰려면 index.html 안의 SERVER_URL="" 에 Render 주소를 넣어요.
